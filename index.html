Listening - Personal Spotify Analytics Dashboard

A passion project combining my love of music with data analytics: a personal dashboard that continuously ingests my own Spotify listening history and visualizes it - top tracks and artists over time, a day/hour listening activity heatmap, top albums, and new-artist discovery trends, alongside a live "now playing" widget.

  • Built an automated ETL pipeline that polls the Spotify Web API and upserts listening history into a hosted database
  • Designed a dark, custom-themed UI/UX with hand-built charts (activity heatmap, genre/album breakdowns, discovery trend lines) rather than an off-the-shelf dashboard kit
  • Worked around real-world API constraints (Spotify deprecating endpoints/fields mid-project) by redesigning the analytics around the data that remained available
  • Utilized: Next.js, TypeScript, Tailwind CSS, Recharts, Framer Motion, Turso (libSQL), GitHub Actions
